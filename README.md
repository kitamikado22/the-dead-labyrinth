## 概要
コンソール上で遊べる疑似3Dダンジョンゲーム。ランダムに生成されるダンジョンを探索して、迷宮奥底に眠る宝石を手に入れて、拠点まで帰るゲームです。道中は罠や敵など様々な困難が待ち受けています。

## 遊び方
`TheDeadLabyrinth.exe`を起動します。コンソールのフォントによっては表示が崩れます。ゴシック体などのどんな文字も全角：半角が2：1であるフォントを使用すると良いです。

WASDキーとEnterキーとBackSpaceキーのみで遊べます。

- プレイモード
  - W：前に動く
  - A：左に回転
  - D：右に回転
  - Enter：メニューを開く
- メニューモード、戦闘モード
  - W：カーソルを上に動かす
  - S：カーソルを下に動かす
  - Enter：選択を確定する
  - BackSpace：前の選択に戻る

## 目的
当時、授業でC言語を学んだことで自分でもゲームが作れると思い作り始めました。
また「ウィザードリィ」と「世界樹の迷宮」にハマっており、その影響を受けて自分でも3Dダンジョンゲームを作りたいと思ったからです。
